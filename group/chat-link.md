# 群邀请链接规范

邀请邮件的入口是一条群邀请链接。本单元规范链接的取法、寿命与批量取用。

## 身份

外部群机器人取不到链接：外部群的机器人身份调 `chats link` 取不到，须用有权限的用户身份（`--as user`）取。

```bash
lark-cli im chats link --chat-id "$CHAT_ID" --as user --format json
```

`chat_id` 一次性定位：用 `im +chat-search` 按群名搜出 `chat_id`，一次即可，后续复用。

## 寿命

链接非永久：实测 `is_permanent: false`，过期后重发是常规动作，不视为异常。发信前须确认链接仍可用，过期则重取。

## 先取后发

组正文前先取链接：链接在发信前先取，按 `as` 起名，正文以 `{{邀请链接}}` 占位引用。先取后发，不在正文里硬编码链接。

## 批量取链

每轮取一次、轮内复用、过期重取：批量发送时每轮开头取一条链接，轮内各封复用；轮内若链接过期则当场重取，不沿用失效链接。
